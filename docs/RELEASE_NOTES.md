# EvidenceForge 0.1.0

Initial local portfolio release, 2026-11-16. Developed with AI assistance; the
author should be able to explain and reproduce each claimed capability.

## Included

- Three retrieval systems: explicit BM25 baseline, pinned BGE ONNX embeddings with
  exact cosine search, and RRF over the two candidate lists.
- A real CPU experiment over 5,183 BEIR/SciFact documents and all 300 test queries.
- Config/model/data/source fingerprints, full ranked IDs, per-query metrics,
  paired bootstrap intervals, timings and an interactive local report.
- Citation integrity checks, an authored offline boundary demo, and an optional
  one-call Responses API adapter with sanitized failure artifacts.
- Network-free unit tests and GitHub Actions definitions. Remote Actions have
  not been executed for this local release.

## Reproducibility scope

The included experiment keeps its original `frozen-config.json` and source hashes.
An initial attempt using batches of 16 was stopped during corpus encoding, before
any test-query evaluation. CPU profiling on 16 unlabeled corpus documents favored
single-document batches with four threads; that execution configuration was
frozen for the completed run. Retrieval-quality parameters were not tuned.
`scripts/verify_example.py` checks scientific module hashes and
recomputes all metrics/intervals from the saved rankings and relevance judgments.
It does not establish cryptographic authorship or prove that saved rankings were
generated by a trusted machine. Re-running inference is the independent check.

Only retrieval inference was executed. Generative-provider tests use mocks; no
answer-level LLM benchmark, live API call, production deployment, or financial
impact is claimed. Benchmark uncertainty is conditional on these public queries;
it does not account for all dataset/model biases or multiple-comparison selection.

The report has query and document IDs rather than original copyrighted abstracts.
Use the downloader and local `search` command to inspect source documents under
their upstream terms. See [data/model attribution](DATA_AND_MODELS.md).
